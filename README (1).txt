GUJJAR SHOES SHOP — WEBSITE STARTER

FILES
- index.html  : website structure
- style.css   : all styling and responsive layout
- script.js   : product catalogue, search, filters, cart and WhatsApp ordering

HOW TO RUN
1. Extract this ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser (or use the Live Server extension).
4. Keep all three files in the same folder.

WHATSAPP

IMPORTANT BEFORE PUBLIC LAUNCH
- Product names, prices, sizes and stock are demo/sample details. Replace them with your actual inventory.
- Product photos are remote Unsplash demo images; replace them with photos of the actual shoes you sell and confirm image-use permissions/licensing.
- WhatsApp ordering opens a pre-filled message. The customer still has to press Send in WhatsApp.
- This is a front-end storefront, not a payment gateway or inventory database. Hosting/domain and backend can be added separately.

ADDED CUSTOMER FEATURES
- Complaint / feedback form that opens a pre-filled WhatsApp message.
- 1-to-5-star customer rating and review form.
- Reviews entered in the demo are stored in the visitor's browser localStorage only.
- A real public review system visible to all customers needs a backend/database and moderation.
